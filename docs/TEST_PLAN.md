## Release gate

Never mark as stable or publish a "100% no disconnect" guarantee. Require successful CI, user-permission checks, device tests, and repeated real match observations. A debug APK generated by CI is not proof of these conditions.

## New v0.2 acceptance checks

| Test | Expectation |
|---|---|
| Rotate screen after profile import | Profile remains in app process memory; private keys never persisted |
| Match protection toggled ON | Two HTTPS watchdog failures WARN only, do not deliberately switch routes |
| Match protection OFF | Repeated health-check failures request a best-effort VPN stop |
| Direct vs VPN comparison | Both measurements use same HTTPS target, do not change VPN configuration |
| Primary test endpoint unreachable | Comparison uses the SECOND HTTPS endpoint for BOTH routes |
| VPN disconnect failure | App displays warning instead of falsely claiming a safe fallback |
| Process killed and restarted | Profile needs manual re-import; no embedded credentials or silent reconnect |

These scenarios require real device validation. WireGuard configured VPN and server availability are prerequisites.
