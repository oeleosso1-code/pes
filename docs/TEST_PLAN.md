## Required Android tests (not yet executed)

| Scenario | Expected result |
|---|---|
| Open app, no configuration | Diagnostic UI works, VPN remains OFF |
| No internet | Clear offline status, no VPN activation |
| Cancel VPN permission | No routing changes |
| Valid WireGuard config, valid relay | Handshake + tunneled HTTPS => ON |
| Wrong endpoint/no network | VPN fail-safe attempts DOWN |
| Server stops after connection | After two failed 35s checks, best-effort DOWN |
| WireGuard config with ExcludedApplications | Reject imported config |
| eFootball not installed | No VPN activation |
| WireGuard config uses IPv4/IPv6 | Check DNS, route coverage and leaks on phone |
| Android Block connections without VPN | Explicit warning: direct fallback may be blocked |
| Switch Wi-Fi to cellular | Connection mode and game test; no claim of zero disconnect |
| Battery saver/background | Check actual VpnService lifecycle and reliability |
| Android 14/15/16 | Test on real hardware, not emulator only |
| During multiplayer match | No automatic route switching; compare direct vs VPN using in-game indicators |

## Release gate

Never mark as stable or publish a "100% no disconnect" guarantee. Require successful CI, user-permission checks, device tests, and repeated real match observations. A debug APK generated by CI is not proof of these conditions.
